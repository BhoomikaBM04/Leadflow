LeadFlow CRM

About the Project

LeadFlow CRM is a web application that helps administrators manage customer leads. It allows users to add leads, update their status, search records, and manage follow-up notes.

Features

- Admin login and logout
- Dashboard
- Add new leads
- Search and filter leads
- Update lead status
- Add follow-up notes
- Delete leads
- Save records in an SQLite database

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run "npm install".
4. Run "node server.js".
5. Open "http://localhost:3000" in your browser.

Conclusion

LeadFlow CRM makes customer lead management simple and organized through a web-based dashboard.
